# Dart - Asynchronous

Dans ce projet nous allons poursuivre la découverte des bases de Dart.
Nous allons voir :
  - Comment utiliser async/await pour gérer des opérations asynchrones.
  - Comment utiliser Future et les opérations délayées.
  - Comment gérer les erreurs en utilisant try/catch.
  - Comment Parse des données JSON provenant d'une réponse d'une API.
  - Comment faire les requêtes HTTP à des API externes.

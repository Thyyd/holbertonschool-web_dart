# Dart - Hello Dart

Dans ce projet nous allons découvrir les bases de Dart, un langage de programmation mobile développé par Google.
Nous allons voir :
  - La structure de base et la syntaxe de Dart
  - Comment déclarer et utiliser des variables de types communs (int, string, double)
  - Afficher des données et intéragir avec des simples opérations dans la console
  - Quel est le rôle de la fonction main()

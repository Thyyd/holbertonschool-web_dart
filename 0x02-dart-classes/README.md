# Dart - Dart Function

Dans ce projet nous allons poursuivre la découverte des bases de Dart.
Nous allons voir :
  - Comment créer une classe basique avec des propriétés et des méthodes.
  - Comment utiliser des constructeurs pour créer des objets.
  - Comment convertir des objets de/vers JSON en utilisant les méthodes correspondantes.
  - Comment utiliser l'héritage.
